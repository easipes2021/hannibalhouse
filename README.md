# 🏠 Hannibal House Dashboard

A premium, high-performance dashboard for managing home maintenance, renovations, and cleaning tasks. Built with Vanilla JS and CSS for maximum speed and compatibility.

## ✨ Features
- **Task Management**: Create, track, and manage home work orders.
- **Smart Prioritization**: Sort tasks by price, difficulty, time, or priority levels.
- **CSV Import**: Upload your existing spreadsheets to quickly populate your dashboard.
- **Persistence**: All data is saved locally to your browser.
- **Premium Design**: Dark mode interface with glassmorphism and smooth animations.
- **Repeated Tasks**: Set reminders for recurring maintenance.

## 🚀 Getting Started
1. Clone the repository to your local machine.
2. Open `index.html` in any modern web browser.
3. Start adding tasks or import your CSV!

## 📤 CSV Import Format
For best results, your CSV should have headers similar to:
`Title, Room, Category, Priority, Price, Difficulty, Time`

## 🛠 Tech Stack
- HTML5 / CSS3
- Vanilla JavaScript (ES6+)
- [Lucide Icons](https://lucide.dev/)
- [PapaParse](https://www.papaparse.com/) for CSV handling
- [Google Fonts](https://fonts.google.com/specimen/Outfit) (Outfit)

## 🌐 Hosting on GitHub
1. Create a new repository on GitHub.
2. Follow the instructions to push your existing repository:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/hannibal-house-dashboard.git
   git branch -M main
   git push -u origin main
   ```
3. Go to **Settings > Pages** and set the source to the `main` branch to host it for free!
